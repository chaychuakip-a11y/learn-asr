# 01：心智模型与第一次完整闭环

## 本课目标

学完本课，你应能解释 Codex 与普通聊天机器人的关键区别，并独立完成一次“调查—行动—验证—汇报”的闭环。

## 1. Codex 不是自动补全，而是受约束的工程代理

普通问答通常只生成文字。Codex 在获得相应权限后，还可以读取文件、搜索代码、运行命令、编辑文件和检查结果。

你仍然是负责人。你的工作不是逐行告诉它如何编码，而是提供：

- 目标：最终要发生什么变化。
- 上下文：哪些文件、错误、示例和背景有关。
- 约束：不能破坏什么，必须遵守什么。
- 完成标准：用什么证据判断完成。

这四项是整套课程最重要的框架，简称 **GCCD**：Goal、Context、Constraints、Done when。

## 2. 一次任务的真实生命周期

```text
你的目标
  ↓
Codex 调查当前状态
  ↓
形成假设或计划
  ↓
读取 / 修改 / 运行工具
  ↓
验证结果是否满足完成标准
  ↓
汇报结果、证据、风险和遗留项
  ↓
你审查并决定接受、追问或回退
```

最常见的新手错误，是从“你的目标”直接跳到“请给我代码”，忽略当前状态和验证。

## 3. 五类请求，权限完全不同

| 请求 | Codex 应做什么 | 默认是否改文件 |
|---|---|---:|
| 解释 | 讲清概念或现有代码 | 否 |
| 调查 | 搜集事实、定位相关位置 | 否 |
| 诊断 | 找出原因并提供证据 | 否 |
| 修改 | 实施变更并验证 | 是 |
| 审查 | 寻找 bug、风险、回归 | 否 |

“看看这个报错”通常只授权调查或诊断，并不等于“修好它”。如果你希望修改，要明确说“找到根因后直接修复，并运行相关测试”。

## 4. 当前工作目录就是重要上下文

本课程的真实项目是 `G:\learn_asr`。Codex 可以看到哪个目录，决定了它能使用哪些代码和说明。

第一次任务先让它只读调查：

```text
请只读调查当前仓库，不要修改文件。

目标：用初学者能理解的语言解释这个项目是做什么的。
上下文：重点查看 README.md、pyproject.toml、tests/ 和 acoustic_engine/。
约束：不要运行耗时训练，不要联网，不要改文件；不确定的地方明确标记。
完成标准：给出 1）项目目标，2）目录地图，3）最小运行入口，
4）测试命令，5）每项结论对应的文件证据。
```

观察 Codex 是否真的读取了文件，以及结论能否对应到具体证据。

## 5. 工具输出比语气更可信

以下证据从弱到强：

1. “应该可以。”
2. “我检查过代码。”
3. 给出修改的文件名和逻辑说明。
4. 展示针对性测试已通过。
5. 同时通过测试、静态检查、运行时复现，并审查差异。

不是所有任务都需要第 5 级，但高风险任务需要更强证据。教程文字的小改动可以检查链接和差异；训练、部署或数据处理代码则需要相应测试和运行验证。

## 6. 权限与安全

Codex 的批准策略决定何时询问你，沙箱决定它能访问和修改什么。初学阶段保持默认权限；遇到授权请求时先问三件事：

1. 它准备执行的动作是什么？
2. 精确目标是什么？
3. 失败后是否可恢复？

删除文件、覆盖数据、发布、付款、发送消息、改线上服务都属于需要额外谨慎的动作。不要因为“让它继续”而盲目扩大权限。

## 7. `/compact` 到底做什么

长聊天会积累大量上下文。`/compact` 把较早内容压缩成摘要，保留继续工作的关键信息。它不是：

- 清空项目文件；
- 回退代码；
- 开启新任务；
- 自动修复混乱的需求。

同一个连贯任务可以继续留在原聊天并适时 compact。目标已经变化时，应新开聊天；一个问题出现两个真正不同的解法分支时，可以 fork。

## 8. 第一次“改动闭环”练习

完成上一节只读调查后，在同一聊天发送：

```text
现在实施一个低风险改动：在不改变任何程序行为的前提下，
修正 README.md 中你能确认存在的一处表达或导航问题。

先说明准备改哪里和依据，再编辑；保留用户已有改动。
完成后检查 git diff，验证 Markdown 链接或相关测试，并汇报：
改了什么、为什么、验证证据、仍有什么不确定。
如果找不到可确认的问题，不要强行修改，直接说明调查结果。
```

这里最重要的不是一定产生改动，而是让 Codex尊重证据。如果没有问题，“不改”可能比制造一个无意义 diff 更正确。

## 本课验收

不看正文，用自己的话回答：

1. GCCD 四项分别是什么？
2. “诊断”为什么不自动包含“修复”？
3. 为什么测试输出通常比“已经修好了”更可信？
4. 什么时候应该 compact，什么时候应该新开聊天？
5. 你刚才的练习用了哪些证据？

五题能答对四题，并完成一次只读调查，才进入第 02 课。
