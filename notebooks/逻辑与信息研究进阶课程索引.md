# 逻辑与信息研究进阶课程索引

这条路线补足“逻辑拓展能力”和“信息收集能力”。它不是阅读清单，而是八次有交付物的研究训练。

## 开始前

- 先读仓库根目录的 [逻辑与信息研究进阶手册](../LOGIC_INFORMATION_RESEARCH.md)。
- 运行环境继续使用 VS Code + Jupyter 扩展，或在仓库根目录运行 jupyter lab。
- 原始 Notebook 不保存输出；可复查的已运行版本位于 _executed/information_reasoning。
- 研究工作台说明位于 [research_workspace/README.md](../research_workspace/README.md)。

## 建议节奏

第 1 周完成 01～02，第 2 周完成 03～04，第 3 周完成 05～06，第 4 周完成 07～08。每周末用一个新的 ASR 问题做迁移，不看旧答案从空白开始。

不要以“看完 Notebook”计完成。每课的最小完成条件是：

1. 先写预测和置信度。
2. 运行并理解至少三个代码实验。
3. 完成真实信息搜集实作。
4. 保存支持与反对材料及排除理由。
5. 闭卷完成挑战。
6. 记录什么改变了你的判断。

## 第一个项目

推荐从这个问题开始：

“为什么某段音频的 ASR 结果差，证据足以支持哪个原因？”

先用音频软件观察波形、峰值、RMS、频谱和削波；再分别建立输入质量、说话人域偏移、标签、模型和解码器解释。不要把“幅值低于 1000”当普遍规则：原始 PCM 幅值依赖位深与缩放，专业判断应优先使用相对于满刻度的 dBFS、RMS/LUFS、信噪比和具体任务表现。

## 验收标准

完成路线后，你应能在没有模板提示时：

- 把一个含糊问题改写为带对象、比较、指标、时间与约束的研究问题。
- 正确区分必要与充分、全称与存在、相关与因果。
- 为偏好解释提出至少两个可信替代解释和区分性预测。
- 设计可复查的布尔检索与反方检索。
- 识别转载链和同一研究的多个版本。
- 建立来源家族级证据矩阵并解释冲突。
- 输出有置信度、边界和更新触发器的暂定结论。
