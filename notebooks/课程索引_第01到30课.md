# ASR 从零到量化部署：第 1～30 课（旧阶段索引）

课程现已扩充到音频前端与语义模块。请使用 [第 1～41 课完整索引](课程索引_第01到41课.md)。

启动：

```powershell
uv run jupyter lab
```

优先打开不带“已运行”后缀的 Notebook，自己逐格运行；需要核对结果时再打开“已运行”版本。

## 第一阶段：声音与声学特征（1～6）

1. 声音、采样率、波形和 dB
2. 分帧、加窗与帧移
3. 频谱、DFT 与 FFT
4. STFT 与声谱图
5. Mel 与 Log-Mel
6. 封装声学前端并对照 Librosa

目标：能够从 wav 独立计算并解释 Log-Mel。

## 第二阶段：张量与编码器（7～9）

7. Batch、Padding、Length 与 Mask
8. PyTorch 张量与最小声学编码器
9. 一维卷积、上下文与时间下采样

目标：能够跟踪 shape、有效长度、mask 和下采样时间轴。

## 第三阶段：CTC 核心（10～14）

10. 从未知对齐到 CTC，兼顾流式
11. CTC 前向算法、动态规划与 LogSumExp
12. PyTorch CTCLoss：shape、length 与排错
13. Greedy 与 Prefix Beam Search
14. 真实开源音频上的最小 CTC 训练实验

目标：理解 CTC loss，能够实现 prefix beam，并完成真实音频小实验。

## 第四阶段：流式、PGS 与性能（15～18）

15. 流式特征：Chunk 与缓存
16. 流式编码器：因果卷积与 Chunk Attention
17. PGS 动态修正：`apd`、`rpl`、`rg`
18. RTF 实时率、延迟、吞吐与 Benchmark

目标：维护前端/编码器状态，正确合并增量结果，并区分 RTF 与用户延迟。

## 第五阶段：语言模型与 WFST（19～23）

19. N-gram 语言模型、概率、困惑度与回退
20. CTC 融合 LM、Hotword 与分数调节
21. FSA/WFST：状态、弧、权重和最短路径
22. L、G、HCLG 与 CTC 解码图
23. 流式 Beam/WFST 状态、Lattice 与热词

目标：理解语言模型如何进入搜索，解释解码图、active state 和 lattice。

## 第六阶段：流式系统综合（24）

24. 流式 CTC 系统综合实验与验收

目标：把前端、编码器、解码器、PGS、LM/WFST 与性能指标组成可测试接口。

## 第七阶段：量化与部署（25～30）

25. 模型导出：ONNX 与运行时一致性
26. INT8 量化基础：PTQ、QAT 与误差
27. ONNX Runtime INT8 量化与 Benchmark
28. FastAPI HTTP 推理服务与模型契约
29. WebSocket 流式服务、会话状态与 PGS
30. 生产部署：容器、并发、监控、灰度与验收

目标：能够导出带 cache 的模型，验证 INT8 精度与性能，运行 HTTP/WebSocket 服务，并完成生产验收设计。

## 四遍学习法

1. 第一遍只看图和解释。
2. 第二遍逐格运行并修改参数。
3. 第三遍关闭答案完成练习。
4. 第四遍从空白 cell 重写核心函数。

CTC 必写：collapse、forward algorithm、CTCLoss batch、prefix beam。

流式必写：StreamingFramer、causal cache、PGS buffer、stateful decoder。

部署必做：PyTorch/ONNX 一致性、FP32/INT8 对比、RTF/P99、HTTP/WebSocket 状态隔离和灰度回滚方案。
