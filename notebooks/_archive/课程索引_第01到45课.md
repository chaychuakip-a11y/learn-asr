# ASR 完整课程索引：零基础 PyTorch 到前沿音频语言模型

## 开始之前

```powershell
uv sync --locked
uv run jupyter lab
```

几乎没有基础时，先完成 [PyTorch 零基础导学与 6 节桥梁课](PyTorch零基础课程索引.md)，再进入正式 ASR 主线。每节课都保留练习；正式课和基础课同时提供无输出学习版与 `_已运行.ipynb` 对照版。

## 完整路线

| 阶段 | 课次 | 核心内容 | 阶段成果 |
|---|---:|---|---|
| Python/PyTorch 预备 | 导学＋基础 1～6 | 语法、Tensor、广播、autograd、nn.Module、DataLoader | 能写训练循环和变长语音 batch |
| 声音与特征 | 1～6 | 采样、FFT、STFT、Mel、Log-Mel | 手写并验证声学前端 |
| PyTorch 编码器 | 7～9 | padding/mask、Linear、Conv1d、下采样 | 实现最小声学编码器 |
| CTC | 10～14 | 对齐、动态规划、loss、greedy/beam、真实训练 | 完成最小端到端识别训练 |
| 流式 ASR | 15～18 | chunk/cache、因果模型、PGS、RTF/延迟 | 验证离线/在线一致性 |
| LM 与 WFST | 19～23 | N-gram、浅融合、热词、FST、lattice | 实现可解释的图搜索解码 |
| 系统综合 | 24 | 接口、状态、验收矩阵 | 组合可测试流式 CTC 系统 |
| 量化部署 | 25～30 | ONNX、INT8、HTTP/WebSocket、容器、监控 | 部署并比较质量—性能 |
| 音频前端 | 31～36 | 输入审计、降噪、VAD、AEC、波束形成 | 完成麦克风到模型前端 |
| 后处理语义 | 37～41 | 时间戳、说话人、ITN、置信度、NLU、LLM | 构建保留证据的语音应用 |
| 前沿模型 | 42～45 | Conformer、RNN-T/TDT、自监督、AudioEncoder＋LLM | 理解现代流式与 LALM 路线 |

第 1～41 课的逐阶段说明见 [核心课程索引](课程索引_第01到41课.md)。下面列出新增前沿课和贯穿主线的专题实验室。

## 推荐顺序

- 完整零基础路线：`导学 → 基础1～6 → 1～14 → CTC专题 → 15～24 → 流式/WFST专题 → 25～41 → 量化专题 → 42～45`。
- 最短建模主线：`基础2～6 → 1 → 5 → 7～16 → 18 → 24 → 42～45`。
- 部署路线：先完成 1～18 和 24，再学 25～30 与量化专题。

课程文件生成完毕不等于学习完成。真正通关要求在 `LEARNING_LOG.md` 中留下闭卷解释、独立实现、排错和迁移证据。
