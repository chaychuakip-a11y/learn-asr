# ASR 从零到流式 CTC：第 1～24 课（旧阶段索引）

课程现已扩充到量化与生产部署。请使用 [第 1～30 课完整索引](课程索引_第01到30课.md)。

启动环境：

```powershell
uv run jupyter lab
```

建议优先打开不带“已运行”后缀的 Notebook，自己逐格运行；遇到问题时再对照“已运行”版本。

## 第一阶段：声音与声学特征（第 1～6 课）

1. 声音、采样率、波形和 dB
2. 分帧、加窗与帧移
3. 频谱、DFT 与 FFT
4. STFT 与声谱图
5. Mel 与 Log-Mel
6. 封装声学前端并对照 Librosa

阶段目标：能够从 wav 独立计算并解释 Log-Mel 特征。

## 第二阶段：张量、变长序列与编码器（第 7～9 课）

7. Batch、Padding、Length 与 Mask
8. PyTorch 张量与最小声学编码器
9. 一维卷积、局部上下文与时间下采样

阶段目标：能够跟踪 `[N,T,F]`、有效长度、mask 和下采样后的时间轴。

## 第三阶段：CTC 核心（第 10～14 课）

10. 从未知对齐到 CTC，兼顾流式
11. CTC 前向算法、动态规划与 LogSumExp
12. PyTorch CTCLoss：shape、length 与排错
13. CTC Greedy 与 Prefix Beam Search
14. 真实开源音频上的最小 CTC 训练实验

阶段目标：能够解释 CTC loss、实现 prefix beam，并用真实音频训练一个小模型。

## 第四阶段：流式 ASR、PGS 与性能（第 15～18 课）

15. 流式特征：Chunk 与缓存
16. 流式编码器：因果卷积与 Chunk Attention
17. PGS 动态修正：`apd`、`rpl`、`rg`
18. RTF 实时率、延迟、吞吐与基准测试

阶段目标：能够区分 RTF 与延迟，维护前端/编码器缓存，并正确合并动态修正结果。

## 第五阶段：语言模型与 WFST（第 19～23 课）

19. N-gram 语言模型：概率、困惑度与回退
20. CTC 结合语言模型：Hotword 与分数融合
21. FSA 与 WFST：状态、弧、权重和最短路径
22. WFST 组合：L、G、HCLG 与 CTC 解码图
23. 流式 Beam/WFST 状态、Lattice 与热词

阶段目标：理解语言模型怎样进入搜索，能够解释 WFST 图层、lattice、active state 和动态热词。

## 第六阶段：综合验收（第 24 课）

24. 流式 CTC 系统综合实验与验收

阶段目标：把前端、编码器、解码器、PGS、LM/WFST 和性能指标组织成一个可测试的系统接口。

## 推荐学习方式

每课分四遍完成：

1. 第一遍只读图和解释，不纠结公式。
2. 第二遍逐格运行，修改参数观察变化。
3. 第三遍关闭参考答案，完成全部题目。
4. 第四遍从空白 cell 重写该课最核心的函数。

CTC 主线建议重写：`ctc_collapse`、forward algorithm、`CTCLoss` batch、prefix beam search。

流式主线建议重写：`StreamingFramer`、causal cache、PGS buffer、RTF benchmark、stateful decoder。

WFST 主线建议重写：最短路径、composition 的标签匹配、LM score 融合和 lattice N-best。
