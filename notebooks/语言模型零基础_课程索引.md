# ASR 语言模型零基础课程索引

这条路线面向“会一点 Python，但几乎没学过概率、N-gram、FST”的学习者。你不需要先学完整套声学模型课程。课程目标不是背命令，而是最终能独立解释、构建、检查并改进一个从 N-gram 到 WFST、再到现代二遍重打分的 ASR 语言模型系统。

## 先从这里开始

在你克隆的 `learn-asr` 仓库根目录打开 PowerShell：

```powershell
uv sync --locked
uv run jupyter lab
```

然后打开本目录下的 `语言模型零基础_01_从计数到Bigram.ipynb`。

每课有两份 Notebook：

- 不带 `_已运行`：学习版。代码输出已清空，适合自己预测、执行和修改。
- 带 `_已运行`：对照版。保存了本机验证过的输出；卡住时只对照当前小节，不要从头抄答案。

第 1～2 课只需 Python。第 3～8 课需要 Windows、WSL Ubuntu 和 OpenFst；第 5～8 课还需要 KenLM 与 `kaldilm`。安装方法见 [ASR LM 安装与排错](../ASR_LM_ENVIRONMENT.md)。

## 每一课怎样学

1. 先读当前小节，不运行代码，写下你预计的概率、路径、状态数或排序结果。
2. 运行一格，只比较“预测”和“实际”；不一致时先找第一处不一致。
3. 修改一个参数，例如 `k`、N-gram 阶数、LM scale 或候选集大小，再运行。
4. 用自己的话解释“改了什么、为什么结果会这样”。
5. 完成自动判题和离场票。答案之后再发给我批改即可，这不影响你先拿到全部课程材料。
6. 卡住超过 20 分钟时，到 `_executed/language_models/` 查看同名 `_已运行.ipynb` 的当前小节。

## 三个里程碑

### 里程碑 A：概率语言模型（01～02）

你应能从计数写出条件概率，解释零概率、平滑、回退、插值、OOV 和 PPL。此时还不要求会 OpenFst。

### 里程碑 B：可执行解码图（03～06）

你应能把概率变成路径代价，读写 OpenFst 文本格式，构建并组合 `L` 与 `G`，解释 symbol table、epsilon、消歧符号以及 HCLG/CTC-TLG。

### 里程碑 C：现代系统与研究（07～09）

你应能区分一遍解码和二遍重排，使用 oracle WER、coverage–risk 与 Pareto 分析系统，并设计“WFST 保底、检索提供上下文、音频条件模型纠错、置信门控回退”的现代混合方案。

## 最终验收标准

课程材料看完不等于学会。之后进行正式验收时，你需要提供以下证据：

- 不看答案，解释 12 个核心概念：N-gram、PPL、backoff、OOV、semiring、epsilon、composition、determinization、`L/G/H/C`、disambiguation、lattice、oracle WER。
- 从一小段新语料独立训练 3-gram ARPA，并转换成可检查的 `G.fst`。
- 找出一个故意制造的 symbol table 或 `#0` 错误。
- 在开发集选择 LM scale，冻结后只评测一次测试集。
- 为一个领域 ASR 场景写出前沿系统方案及至少 4 个消融实验。

速查时使用 [OpenFst/KenLM 速查表](../ASR_LM_OPENFST_KENLM_CHEATSHEET.md)；遇到安装或命令错误时使用 [安装与排错](../ASR_LM_ENVIRONMENT.md)；前沿论文按 [ASR LM 前沿论文路线](../FRONTIER_ASR_LM_READING.md) 的顺序阅读。
