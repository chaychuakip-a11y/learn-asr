# 音频零基础桥梁课：先理解声音，再进入 ASR 特征

这 6 节课解决从 Python/PyTorch 基础直接进入“采样、FFT、Log-Mel”时常见的知识跳跃。它不要求信号处理背景，按“生活直觉 → 单位和数字 → 图形 → 代码 → 真实 WAV”逐级推进。

## 每课固定方法

1. 先写课前猜测，不查答案。
2. 每个量都用“含义 + 单位 + 数组表示 + 参数变化”解释。
3. 运行代码前画预期图；结果不同时保留错误预测。
4. 完成 12 道分层题，其中第 9～10 题必须从空白实现并测试。
5. 达到 19/24 后继续；明天、7 天、30 天闭卷复习。

## 进入 ASR 主线第 1 课的门槛

- 看到波形 `[T]` 能说明横轴、纵轴、采样率、时长和单位；
- 能换算 Hz、周期、秒、毫秒与采样点数；
- 能区分 peak、RMS、功率、dB 与 dBFS；
- 能解释采样与量化不是一回事，并识别 mono/stereo shape；
- 能合成指定 SNR 的噪声并用测量值验证；
- 能读取真实 WAV，报告采样率、通道、dtype、时长、peak、RMS、DC、clipping 和有限性。
- 能完成根目录的 [专业音频软件分析实验](../AUDIO_SOFTWARE_GUIDE.md)：Audacity 波形/频谱分析、Praat F0/Formant/Intensity/TextGrid，并与 `data/audio_software_lab/manifest.json` 和 Notebook 结果交叉验证。
- 能完成 [24 条音频问题盲诊断](../AUDIO_DIAGNOSIS_PRACTICE.md)中的至少 19 条，并为每条写出两项独立证据，而不是只凭听感猜测。

建议先按 1～6 完成概念与代码，再做 [专业音频软件分析实验](../AUDIO_SOFTWARE_GUIDE.md)和 [24 条音频问题盲诊断](../AUDIO_DIAGNOSIS_PRACTICE.md)，最后进入 [主线第 1～6 课](核心课程索引_第01到41课.md#16声音与声学特征)。主线会在这些直觉和 GUI 测量经验上继续学习 Nyquist/混叠、分帧、FFT、STFT、Mel 和 Log-Mel。
