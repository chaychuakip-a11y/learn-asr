# ASR 完整课程：从麦克风前端到语义与部署

启动：

```powershell
uv run jupyter lab
```

第一次进入课程时，先打开 [`学习中枢_诊断与掌握度仪表盘.ipynb`](学习中枢_诊断与掌握度仪表盘.ipynb)。它提供 24 题分阶段诊断、交互式信号链参数图、八维掌握度图、自动起点推荐和个人进度保存。

每课都有无输出版本和“已运行”对照版本。建议自己逐格运行无输出版本。

## 1～6：声音与声学特征

采样、波形、dB、分帧、窗、FFT、STFT、Mel、Log-Mel 和前端封装。

## 7～9：张量与声学编码器

Batch、Padding、Length、Mask、PyTorch、卷积上下文与时间下采样。

## 10～14：CTC 核心

未知对齐、blank、前向动态规划、LogSumExp、CTCLoss、Greedy、Prefix Beam 和真实音频训练。

完成第 10～13 课后运行 [`专题_CTC可视化实验室_从路径到流式解码.ipynb`](专题_CTC可视化实验室_从路径到流式解码.ipynb)。专题在同一个 `[T,C]` 概率矩阵上把路径穷举、前向表、PyTorch loss、梯度、Prefix Beam 和跨 chunk 状态串起来，并提供 32 分闭卷通关测试。

## 15～18：流式 ASR

Chunk、缓存、因果卷积、Chunk Attention、PGS、RTF、首字/最终延迟与 P99。

## 19～23：语言模型与 WFST

N-gram、困惑度、LM 融合、热词、FSA/FST、L/G/HCLG、CTC 解码图和 lattice。

## 24：流式 CTC 综合实验

把特征、encoder、decoder、PGS、LM/WFST 与性能指标组织成可测试接口。

## 25～30：量化与部署

25. ONNX 导出与运行时一致性
26. INT8、PTQ、QAT 与量化误差
27. ONNX Runtime INT8 与 Benchmark
28. FastAPI HTTP 推理服务
29. WebSocket 流式服务、状态与 PGS
30. Docker、并发、监控、灰度和生产验收

## 31～36：麦克风到模型之间的音频前端

31. 音频输入质量：通道、幅度、DC、削波与重采样
32. 降噪、SNR、AGC 与数据增强
33. VAD、Endpoint 与 Hangover
34. AEC 回声消除、NLMS 与 Double-talk
35. 多麦克风与 Delay-and-Sum 波束形成
36. 流式音频前端总管线与状态

## 37～41：ASR 后处理与语义

37. 时间戳、说话人分段与 Diarization
38. 标点恢复、ITN 与文本规范化
39. 置信度、N-best 与语义重排序
40. NLU 意图识别、槽位抽取与对话状态
41. 受约束 LLM 后处理与端到端语音系统

## 推荐主线

第一次按 `1→10→11→12→13→15→16→17→18→19→20→21→22→24→25→27→29→31→33→36→38→39→40→41` 学习。

其余课程作为专题穿插。每个阶段都应完成：看图、改参数、关闭答案做题、从空白重写核心函数。
